# R22 Clover Bar Railway Bridge — sources

Photos in `photos\` are openly licensed (CC BY-SA or no known copyright restrictions). A file that was useful but not openly licensed is listed under "Not downloaded" with the URL only. Neighbouring highway decks appear in the 2015 elevation; the table says which structure is which.
