# H50 Henday / Yellowhead east: sources

Photos in `photos\` are openly licensed (CC BY-SA 2.0 on Wikimedia Commons). Each is a 1920 px Wikimedia thumbnail. The full originals were not fetched. Nothing in `photos\` was scaled or measured. A file that was useful but not open is listed under "Not downloaded" with the URL only.

Three photos were saved. They are the only open-licence photos found for this junction. Neighbouring junction frames on Commons are different structures and were not saved.
