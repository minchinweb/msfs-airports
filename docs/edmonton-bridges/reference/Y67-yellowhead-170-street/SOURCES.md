No Structurae entry, HistoricPlaces record, or Alberta bridge sheet with a deck elevation was found for STRU 41091. Searches on Structurae and HistoricPlaces returned nothing for this crossing. The City of Edmonton Archives page for bridges covers other structures. The Edmonton City as Museum Project returned nothing on this bridge in search. The City's 170 Street pedestrian bridge page is a different structure near West Edmonton Mall. Its page returned HTTP 502 on fetch on 2026-11-23, and it is not used. The City's freeway conversion page also returned HTTP 502. It was used only through its search summary, which does not mention 170 Street.

The brief asked for the Environment Canada gauge 05DF001. It is not used here. Nothing in the sources converts a gauge reading to a deck elevation for this structure.
