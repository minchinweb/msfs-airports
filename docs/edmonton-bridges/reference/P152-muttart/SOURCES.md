# Muttart stop — sources

Photos in `photos\` are openly licensed (CC BY or CC BY-SA). All four saved files are 1,920 px Wikimedia thumbnails. The full-size originals were not fetched. A file that was useful but not openly licensed is listed under "Not downloaded" with the URL only.

This folder is the stop at the bottom of the Tawatinâ south ramp. The bridge measurements stay in the R14 notes. Davies is not in this folder.
