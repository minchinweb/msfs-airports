# Muttart Conservatory — sources

Photos in `photos\` are openly licensed (public domain, CC0, or CC BY-SA). All three saved files are 1,920 px Wikimedia thumbnails. The full-size originals were not fetched. A file that was useful but not openly licensed is listed under "Not downloaded" with the URL only.

This folder is the conservatory beside the Muttart stop. It is part of that stop scene. It is not a bridge, and it is not its own inventory code. The stop measurements stay in the parent notes.
