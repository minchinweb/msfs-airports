# Y70 street photos: sources

Street-level reference for what a driver sees at and near the 97 Street overpass of Yellowhead Trail. They are not reference for the finished deck. All four are from 2018.

## Licence

The Mapillary API did not return a licence for these images on 2026-11-23. The licence is unconfirmed. Mapillary's default for user images is CC BY-SA 4.0, but that is not confirmed for these images. Creator usernames are kept for attribution.

## Query

Mapillary API v4 images query, 2026-11-23. Bounding box -113.4945, 53.5780, -113.4895, 53.5835 (about 150 m around the mapped structure and its approaches). 180 images returned. None were panoramas. Selection: nearest to the record point (53.581278, -113.492106), at least 30 m apart, four images at most. The key was read from the local file and sent only in the request header.
