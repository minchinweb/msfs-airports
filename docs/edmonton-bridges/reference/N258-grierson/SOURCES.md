# Grierson Hill Bridge — sources

Photos in `photos\` are openly licensed. The one saved file is a 1,920 px Wikimedia thumbnail. The full-size original was not fetched. The original is 4,640 px wide. A file that was useful but not openly licensed is listed under "Not downloaded" with the URL only.

This folder is the road span at the bottom of Grierson Hill. The two Low Level river decks stay in the R13 notes. The 2016 footbridge over the hill road is named here only so it is not drawn as this deck.
