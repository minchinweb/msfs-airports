# R8 Groat Bridge — sources

Photos in `photos\` are openly licensed (CC BY, CC BY-SA, or CC0). A file that was useful but not openly licensed is listed under "Not downloaded" with the URL only. Five of the saved files are 1,920 px Wikimedia thumbnails. The full-size originals were not fetched. `piers-2009.jpg` is the full file. The original is 1,600 px wide.

Photographs taken before the 2018–2020 superstructure replacement show the concrete girders that were removed, and the pier shafts that were kept. The table says which ones those are. The 27 September 2026 frame and the 9 October 2023 frame are after that replacement.
