# R12 James MacDonald Bridge — sources

Photos in `photos\` are openly licensed (CC BY, CC BY-SA, or public domain). A file that was useful but not openly licensed is listed under "Not downloaded" with the URL only. Five of the saved files are 1,920 px Wikimedia thumbnails. `oblique-and-east-ramps.jpg` is the full file, 1,600 px wide. `underside-from-river.jpg` is the full file, 500 px wide.

The Low Level trusses appear in two of the saved frames. The table says which structure is which. Photographs dated June 2008 or later are after the January 2008 reopening described by the Edmonton Journal.
