# Edmonton-area reference material

- `edmonton-vta-back-vfr-terminal-area-chart.pdf` - back of the Edmonton VFR Terminal Area Chart (VTA), downloaded from https://imageserver.fltplan.com/legends/VTA_BACK_EDMONTON.PDF (fltplan.com). Single vector page, 10198 x 6912 pt, text is outlined (not searchable). "NOT FOR NAVIGATION", current-era (post-2013) airspace.
  - Large map: Edmonton Class C common-frequency area with VFR checkpoints/IFR waypoints, including Josephburg, Cooking Lake (CEE7 area), Villeneuve, Namao, Beach Corner, Cement Plant, Twin Island, Gabet etc.
  - Side panels: arrival/departure routes for Edmonton/Villeneuve, Edmonton City ATF (123.2, covers the former CYXD area), Edmonton/Cooking Lake, Edmonton Parkland Executive, Edmonton Intl; heli training areas.
  - Not period-correct for CYXD (closed 2013), but useful for checkpoint names and positions near CEE7 (Cooking Lake) and the Josephburg project.
